# Paper Network

논문 인용 네트워크와 유사도 기반 추천을 시각화하는 웹 애플리케이션입니다. Connected Papers와 유사한 기능을 제공합니다.

## 주요 기능

### 핵심 기능
- **논문 검색**: Semantic Scholar API를 통한 2억+ 논문 검색
- **네트워크 시각화**: Cytoscape.js를 활용한 인터랙티브 그래프
- **인용 관계**: 논문 간 인용/참조 관계를 시각적으로 표현
- **유사도 기반 추천**: RAG 방식으로 내용이 유사한 논문 추천
- **필터링**: 인용, 참조, 유사 논문을 선택적으로 표시
- **상세 정보**: 논문의 저자, 연도, 초록 등 상세 정보 제공

### 고급 기능
- **타임라인 레이아웃**: 연도별로 논문을 정렬하여 연구 흐름 파악
- **네트워크 확장**: 노드 더블클릭으로 해당 논문 중심으로 재탐색
- **URL 공유**: 특정 논문 네트워크를 URL로 공유
- **이미지 내보내기**: PNG/JPG 형식으로 네트워크 저장

## 기술 스택

- **Frontend**: Next.js 15 (App Router) + TypeScript
- **시각화**: Cytoscape.js
- **상태 관리**: TanStack React Query
- **스타일링**: Tailwind CSS
- **API**: Semantic Scholar Graph API

## 사용 방법

### 기본 사용법
1. 검색창에 논문 제목이나 키워드를 입력합니다
2. 검색 결과에서 원하는 논문을 선택합니다
3. 선택한 논문을 중심으로 네트워크가 시각화됩니다:
   - 🟢 **녹색 엣지**: 이 논문을 인용한 논문들
   - 🔵 **파란색 엣지**: 이 논문이 참조한 논문들
   - 🟡 **주황색 점선**: 내용이 유사한 논문들 (RAG 기반)

### 인터랙티브 기능
- **레이아웃 전환**: 네트워크 ↔ 타임라인 버튼으로 시각화 방식 변경
- **필터링**: 인용/참조/유사 체크박스로 원하는 관계만 표시
- **노드 클릭**: 논문 상세 정보 확인
- **노드 더블클릭**: 해당 논문을 중심으로 네트워크 재구성
- **확대/축소**: 마우스 휠 또는 +/- 버튼
- **드래그**: 네트워크 이동 및 노드 재배치

### 공유 및 저장
- **🔗 공유 버튼**: 현재 네트워크 URL 복사
- **📷 PNG / 🖼️ JPG**: 네트워크를 이미지로 저장

## 기술적 특징

### 유사도 계산
- **Semantic Scholar Recommendations API**: 논문 내용 기반 추천
- **임베딩 지원**: OpenAI API를 통한 커스텀 유사도 계산 (선택사항)

### 성능 최적화
- **점진적 로딩**: 인용/참조/유사 논문을 병렬로 로드
- **캐싱**: React Query를 통한 자동 캐싱
- **효율적 렌더링**: Cytoscape.js의 최적화된 그래프 렌더링
- **필터링**: 클라이언트 사이드 필터링으로 빠른 전환

### 네트워크 시각화
- **두 가지 레이아웃**:
  - **Force-directed**: 관계 밀도를 반영한 자연스러운 배치
  - **Timeline**: 연도별 정렬로 연구 흐름 파악
- **엣지 타입별 색상**: 관계 유형을 직관적으로 표현
- **노드 크기**: 인용 수에 비례하여 중요도 시각화
- **확장 가능**: 더블클릭으로 무한 탐색
- **이미지 내보내기**: 고해상도 PNG/JPG 저장
- **URL 공유**: 특정 네트워크 상태 공유

## 환경 변수 (선택사항)

OpenAI를 사용한 커스텀 임베딩을 원하는 경우:

```bash
OPENAI_API_KEY=your_openai_api_key_here
```

없어도 Semantic Scholar의 추천 기능이 동작합니다.
